## Decisions

Go directive 1.25.5 follows pkgs/cf. Explicit client ID is required for select, server selection is explicit or Rex default with `--autostart=false`; no app/session mutation in unit tests. Stream starts before snapshot; no revision/replay guarantee, and reconnect requires a fresh snapshot. Project reuse requires a verified cwd, not a label match. Inspect populates terminal Block.CWD from Rex foreground process cwd, falling back to local OSC-7 terminal pwd when necessary; file URLs are decoded and only existing absolute directories are symlink-resolved to canonical paths. Unresolved/nonlocal cwd stays empty. No terminal preview polling.
